Report a bug

No account needed. Only the developer reads your report.

The report form isn't switched on yet. It will be soon. Until then you can report on GitHub (needs a GitHub account, and what you write there is public).
What is it?

What you did, what you expected, and what you got instead.

In the game: open Rucksack, click Report a bug, click in the lower box, press Ctrl+C, and paste it here. A copied Lua error is welcome too.

Optional. A character name is fine.
